☁️ Modus B: Deploy with Cloudflare ↗

Ablauf der vollautomatischen Cloud-Installation:

  1. Cloudflare API Token & Account-Berechtigungen validieren
  2. D1 SQL-Datenbank actanex-open-db erstellen / verknüpfen
  3. R2 Object-Storage-Bucket actanex-open-storage erstellen
  4. Sämtliche GoBD- & Schemamigrationen (0001–0020) einspielen
  5. Cloudflare Worker Secrets sicher verschlüsselt speichern (JWT_SECRET, LEXWARE_API_KEY, etc.)
  6. Initialen Administrator-Account mit sicherem Hash und Salt einrichten

🛡️ Pre-Flight Ressourcenprüfung & Überschreibschutz

Prüft Ihren Cloudflare-Account vor der Installation auf Namenskollisionen, um versehentliches Überschreiben zu verhindern.

Worker: Ungeprüft
D1 Datenbank: Ungeprüft

⚠️
Achtung: Kollision mit bestehenden Ressourcen erkannt!

Eine oder mehrere Ressourcen existieren bereits in Ihrem Cloudflare-Account. Bitte passen Sie die Namen in Schritt 2 an oder bestätigen Sie die Überschreibung ausdrücklich.
